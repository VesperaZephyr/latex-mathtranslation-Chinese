## 5. 封面体系（`cover-art.tex`）

**为什么自绘而不是找图**：本环境的沙箱拦截了对外二进制下载（`curl` 到
Wikimedia 返回代理错误页、`urllib` 握手超时），拿不到高分辨率原图。
改用 TikZ 矢量自绘反而更好：任意分辨率不失真、无版权问题、六册严格统一。

**母题**：暮色中的麦田。天空三段渐变（顶／中／地平线）→ 地平线上的落日与双层光晕 →
犁沟按透视收束到地平线灭点 (105,105) → 地平线上的**播种者剪影** → 从掌心撒出的
**种子贝塞尔弧**（26 粒，半径递减，末端散入麦田）→ 前景两排**麦穗剪影**（后排 11 支
半透明、前排 10 支实心）→ 底部深色信息带（麦穗自其后长出）。

**用法**（各卷主控中，顺序固定）：

```latex
\input{common}                                    % 共用导言区
\input{cover-art}                                 % 载入封面定义
\CoverSetup{prelude}{卷一}{前奏}%
            {主题的呈现——或四个乐章的前奏}{p.23–122}
```

`\CoverSetup{配色}{卷次}{卷名}{副题}{原书页码范围}`；正文中再 `\makecover`。
配色关键字与用途：

| 关键字 | 用在哪 | 色调 |
|---|---|---|
| `prelude` | 卷一 | 破晓：深靛蓝 → 琥珀 |
| `part1` | 卷二 | 盛夏：青碧 → 金黄 |
| `part2` | 卷三 | 血色黄昏：暗紫红 → 橙红 |
| `part3` | 卷四 | 暮紫：深蓝紫 → 玫红 |
| `part4` | 卷五 | 夜田：墨绿 → 土黄 |
| `all` | 全书合订 | 麦浪：深褐 → 金 |

**改动须知**：

- `\makecover` 用 `remember picture, overlay` 定位到 `current page.south west`，
  坐标系为 **1mm 单位，页面 210×297**。因此**必须至少跑两遍**才定位正确（构建脚本跑 4 遍）。
- 麦穗宏 `\cvWheatEar{x}{底 y}{高 mm}{倾角}`；地平线在 y=105，麦穗底边在 y=30
  （信息带顶边）。要改构图，先改这两个数。
- 标题字距用 ctex 的 `\ziju{0.08}`（书名）与 `\ziju{0.1}`（卷名）；`\ziju` 由
  ctex 提供，**在本项目可用**（已实测编译通过）。
- 循环变量一律用 `\cvI` / `\cvT` / `\cvK` 等带前缀的名字：
  `\tt` 是 LaTeX 旧字体命令、`\i` `\j` 是无点 i/j，覆盖它们会有隐性风险。

## 7. 版式与体例约定

### 7.1 边码 `\origpage{}`（原打字稿页码，排页边）

| 章 | 形态 | 例 | 坑 |
|---|---|---|---|
| 1 权作序言 | `A1…A6` | `\origpage{A3}` | — |
| 2 巡游 | `P1…P65` | `\origpage{P39}` | **P 是页码的一部分**，不能省 |
| 3 一封信 | `L1…L56` | `\origpage{L47}` | — |
| 4 引言 | 罗马数字 `I…XXII` | `\origpage{VII}` | **不能写成 `P.VII`**，会印成「p. P.VII」 |
| 5–12 第一部 | 纯数字 `1…171` | `\origpage{116}` | — |
| 13 起 | 原打字稿页码 | `\origpage{938}` | 与本排印本页码无关 |

宏定义：`\newcommand{\origpage}[1]{\marginnote{\normalfont\scriptsize p.~#1}}`。

### 7.2 脚注

| 位置 | 宏 | 排印形式 |
|---|---|---|
| 前奏、第一部（**无**连续注号） | `\fnote{编号}{角标}{注文}` | 上标=编号，注文行首 `编号角标` |
| 第一部（**有**连续注号） | `\fnoteP{页内号}{(连续号)}{注文}` | 上标=页内号；正文在序号后**另写** ` (36)`；注文行首印 `1(36)` |
| 第一部，原书**未标**连续注号而改标日期的 3 条 | `\fnoteP{11}{}{(8月8日)……}` | 第二参数留空，日期写进注文之首；**正文不要再写括注** |
| 第二至四部 | `\fnote{795}{(*)}{注文}` | 编号与 `(*)` 角标逐字照抄原书 |
| 标注与注文不一致时 | `\fnotevariant{标注}{角标1}{角标2}{注文}` | 上标用角标1，注文行首用角标2 |

第一部的 50 条注号序列（**第 12 章目录权威**）：
`1…21, 22, 22′, 23, 23′, 23″, 23‴, 23iv, 23v, 24…44`。
**注意**：其中 `23v` 是字母 v、`23iv` 是罗马数字，混在撇号序列里；
ch08 注 9–12 的真值是 `9(23″) 10(23v) 11(23‴) 12(23iv)`，不是四个撇号。
撇号一律写数学模式：`23$''$`、`23$'''$`、`23$^{iv}$`、`23$^{v}$`。

### 7.3 标点（全卷统一，**以成稿为准**，`STYLE.md` 第二节已按现行成稿修订）

- 句末：**。**（全角句号）
- 其余：半角 `, ; : ? ! ( )`，**后不加空格**
- 中文弯引号 `“” ‘’`；书名 `《》`；省略号 `……`；破折号 `——`；顿号 `、`
- 半角标点与汉字之间的空隙由 `xeCJK CJKecglue=0.45em` 统一给，**不要手写空格**
- 反讽引号是作者的标点武器，一对都不能丢

### 7.4 常用宏

| 宏 | 用途 |
|---|---|
| `\pmark` / `\dmark` | 段首 ◇ / 上标 ⋄（补写标记） |
| `\notehead{171³}{斜体评论}` | 大注块标题 |
| `\asterisms` | `∗ ∗ ∗` 分隔 |
| `\tocsubsub{…}` | 无编号子目进目录 |
